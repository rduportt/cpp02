# CPP Module 02

> Ad-hoc polymorphism, operator overloading and the Orthodox Canonical Form.

## What's inside

- Orthodox Canonical Form (constructors, copy, assignment, destructor)
- Fixed-point number class
- Operator overloading
- Bonus: BSP (point in triangle)

## Usage

```bash
cd ex00      # pick an exercise (ex00, ex01, ...)
make
./<executable>
```
Each exercise has its own Makefile and is compiled with `c++ -Wall -Wextra -Werror -std=c++98`.
